# Search, sitemap and admin branding

- `/search?q=admissions` searches page titles, descriptions and keywords, plus public news bodies and download descriptions. Results are ranked by title relevance and paginated in groups of ten. Empty queries and queries with no matches have dedicated messages.
- The header search submits to the results page on desktop and mobile. Escape from the input closes the search and restores focus to its toggle.
- `/sitemap` lists school pages and public news. The footer links to this page. `/sitemap.xml` lists canonical pages and news detail URLs, and `/robots.txt` advertises it. Search results carry a `noindex` directive.
- CMS content uses the existing anonymous-access loaders and follows the legacy, managed or append settings. Legacy resource data is shared with the Resources page in `src/cms/public/legacy-resources.ts`.
- Resources has Latest News, School Calendar and Downloads. Its announcement tab, navigation/search entries, CMS placement and content-source setting have been removed. The top announcement bar and its CMS controls remain available.
- The retired Resources announcement setting remains stored as a hidden compatibility field so development startup does not prompt to delete its database column. It is not used by the website or shown in the CMS.
- Articles support an **Image URL** in the CMS as an alternative to **Uploaded image**. Enter a direct public HTTPS image URL; an HTTPS link takes priority over an upload. Clear the link to use the upload. Existing local image paths remain supported. Linked images load directly in the browser on news lists, homepage cards and article pages; the external host must permit public image access.
- Maintain static page descriptions and search keywords in `src/lib/site-pages.ts` when adding or changing school pages. Search does not crawl rendered page content or PDF contents.
- Set `PUBLIC_SITE_ORIGIN` to the deployment's canonical origin for sitemap and robots URLs. The fallback is `https://www.apollovidhyalayam.com`. The XML sitemap revalidates every 60 seconds.
- The admin login uses `src/components/payload/ApolloLogo.tsx` and the existing `public/apollo-logo.png` asset through Payload's `admin.components.graphics.Logo` setting. Regenerate the import map with `npm run generate:importmap` if the component path changes.

Validation for the Resources and image URL changes: the 170-test unit suite passed, followed by 22 focused checks after adding compatibility handling for existing announcement placements. TypeScript, lint and whitespace checks passed. The local server startup blocker was resolved by retaining the retired database field as hidden. Browser checks verified all three Resources tabs, fallback from the retired announcements URL, and no page errors. A controlled external-image browser fixture verified direct URL rendering through Next Image; live article imagery was unavailable because the current news list was empty.
